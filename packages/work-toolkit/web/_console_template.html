使用边界

配置写入每个开关都调用 /api/config/toggle，写入前用 tomllib 校验，写入后重新读取状态。
接口与 MCP本页接口直接调用仓库内模块；Codex 是否可用取决于 config.toml、Skills 目录以及是否重启 Codex。
按需读取通讯、Office、记忆、轨迹、工作区数据只在切到对应视图并点击刷新时读取。
写文件聊天汇总、经验提炼、Obsidian 导出等写操作由用户点击触发；页面加载不自动写业务文件。
